# 景点速查页改版实施计划 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有“骑行攻略解析页”改造成“景点速查页”，保留粘贴链接解析的主链路，并把结果内容改为景点亮点、打卡点、小吃文创、周边推荐和补充信息。

**Architecture:** 继续沿用现有单页 React + zustand 架构，只替换与骑行语义强绑定的类型、mock 解析结果和结果展示组件。输入区、状态流、错误弹窗、加载态和基础样式尽量复用，以最小范围完成产品定位切换。

**Tech Stack:** React 18、TypeScript、Vite、Tailwind CSS、Zustand、Vitest

```ts
export type ParseErrorCode = "INVALID_INPUT" | "TIMEOUT" | "PARSE_FAILED" | "ABORTED"

export type SpotGuide = {
  source: {
    rawInput: string
    kind: "url" | "text"
  }
  coreSpot: {
    title: string
    city?: string
    summary: string
    bestTime?: string
    audienceTags: string[]
  }
  highlights: Array<{
    title: string
    description: string
  }>
  checkpoints: Array<{
    name: string
    description: string
    photoTip?: string
    stayHint?: string
  }>
  foodAndSouvenirs: Array<{
    name: string
    category: "food" | "souvenir"
    reason: string
  }>
  nearbyRecommendations: Array<{
    name: string
    reason: string
    relationHint?: string
  }>
  extraInfo: {
    transportTags: string[]
    stayTags: string[]
    durationHint?: string
    tips: string[]
  }
}

export type ParseInput = {
  text: string
}

export type ParseResult =
  | { ok: true; data: SpotGuide }
  | { ok: false; errorCode: ParseErrorCode; message: string }

export interface ParserAdapter {
  parse(input: ParseInput, signal?: AbortSignal): Promise<ParseResult>
}
```
