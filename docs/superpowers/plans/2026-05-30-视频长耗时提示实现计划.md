# 视频长耗时提示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不打断视频请求的前提下，为 Kimi 视频分析阶段增加长耗时提示，让用户知道页面仍在处理中。

**Architecture:** 沿用现有 Zustand 视频状态流，只在 `analyzing_video` 阶段增加轻量等待级别状态，并由 `StatusBanner` 根据等待级别切换文案。实现不改 Kimi 请求协议，不新增后端，不改变成功、降级和失败分支。

**Tech Stack:** React 18, TypeScript, Zustand, Vitest, Vite

- [ ] **Step 3: Write minimal implementation**

```ts
type VideoAnalyzeWaitLevel = "normal" | "slow" | "very_slow"

let videoAnalyzeTimer: ReturnType<typeof setTimeout> | null = null

function clearVideoAnalyzeTimer() {
  if (videoAnalyzeTimer) {
    clearTimeout(videoAnalyzeTimer)
    videoAnalyzeTimer = null
  }
}

function scheduleVideoAnalyzeHints(set: SetState<RideGuideState>) {
  clearVideoAnalyzeTimer()
  videoAnalyzeTimer = setTimeout(() => {
    set({ videoAnalyzeWaitLevel: "slow" })
    videoAnalyzeTimer = setTimeout(() => {
      set({ videoAnalyzeWaitLevel: "very_slow" })
    }, 30_000)
  }, 15_000)
}
```
